# 전세 체크리스트 코치

등기부등본(+계약서는 선택)을 올리면 등기부를 쉬운 말로 요약하고, 국토교통부 안내서 체크리스트에 따라 계약 전·계약할 때·계약 후에 확인할 17가지를 근거와 함께 알려주는 웹앱입니다.

> 이 도구는 법률 자문이 아니라 "확인을 돕는 도구"입니다.

## 실행 방법

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 규칙 엔진·체크리스트·등기부 추출·설명 검사 테스트 (Vitest)
```

등기부·계약서 읽기와 쉬운 설명은 `.env.local`의 Anthropic API 키가 필요합니다(커밋 금지). 등기부 한 건에 약 $0.01~0.04, 계약서 한 건에 약 $0.01이 듭니다(v0.3·v0.4 측정).

```
ANTHROPIC_API_KEY=발급받은_키
```

Node 24, npm 11에서 확인했습니다.

## 구조

- `src/rules/config.ts`: 위험 기준값과 출처·기준일
- `src/rules/engine.ts`: 위험 규칙 계산 (순수 함수)
- `src/checklist/`: 체크리스트 17개 항목(승인 문구)과 상태, 등기부 쉬운 요약
- `src/data/regions.ts`: 수도권 판단용 시군구 코드표 (`scripts/build-regions.mjs`로 생성)
- `src/agent/retrieve.ts`, `src/agent/explain.ts`, `src/app/api/explain/route.ts`: 공식 문서 검색과 출처를 단 쉬운 설명
- `src/agent/extract.ts`: 등기부·계약서 → 값과 원문 근거 (AI는 글자만 옮기고 변환·합계·확인 필요 표시는 코드)
- `src/agent/config.ts`: 등기부 읽기 모델 이름, 생각 강도, 업로드 한도
- `src/app/api/extract/route.ts`: 서버에서만 API 키를 쓰는 서류 읽기 경로 (`doc=registry|contract`, 서류는 저장·로그하지 않음)
- `src/app/`: 서류 올리기·확인 화면, 직접 입력 칸, 체크리스트 화면
- `tests/`: 규칙 엔진, 체크리스트, 등기부·계약서 추출, 설명 검사, 문서 검색 테스트
- `tests/fixtures/`: 테스트용 가상 등기부 4종·계약서 5종과 정답표(`README.md`), `scripts/build-fixtures.mjs`로 생성

## 알려진 한계

- 보증보험(HUG) 판단의 선순위채권은 근저당 채권최고액만 넣어 계산합니다. 실제 HUG 기준은 전세권·임차보증금도 포함합니다.
- 공시가격은 사용자가 직접 입력합니다(부동산공시가격알리미). 자동 조회(국토교통부_공동주택가격정보 API)는 하지 않습니다.
- 보증보험의 주택가격은 자체 해석입니다: 아파트·오피스텔은 사용자가 넣은 집값(HUG는 KB·한국부동산원 시세 우선), 빌라는 공시가격 × 140%. 실제 심사 결과와 다를 수 있습니다.

## 버전 기록

### v0.4 계약서 대조 (2026-10-14)

- 주택임대차계약서(PDF·사진)를 올리면 Claude가 임대인·대리인·소재지(동·호수 포함)·보증금·계약일을 읽어 옴. v0.3과 같은 확인 화면을 거친 값만 씀
- 보증금은 한글 금액("사억원정")과 숫자 금액("₩400,000,000")을 코드가 함께 읽고, 서로 다르면 고르지 않고 "확인 필요"
- 규칙 4(엔진): 이름 정리(띄어쓰기·괄호·가운뎃점) 후 다르면 **위험: 집주인 불일치**, 공동명의 일부·대리인 계약·법인(신탁 포함) 소유는 **주의 + 확인 필요**. 불일치가 우선
- 주소 대조(엔진): 계약서와 등기부의 지번·동·호수 중 하나라도 다르면 **주의 + 확인 필요: 주소 불일치**. 계약서 보증금과 판정 보증금이 다르면 알림
- 규칙 6(엔진): 보증 한도(수도권 7억·그 외 5억), (근저당+보증금) ≤ 주택가격 × 90%, 근저당 ≤ 주택가액 × 60%를 넘으면 **가입 가능성 낮음**. 등급과 별개의 눈에 띄는 상자로 기준·출처·기준일과 함께 표시. 값이 없으면 "판단하려면 이 값이 필요해요"
- config: HUG 주택가격 산정 순서를 원문대로 적고, 이 앱의 방식은 "자체 해석"으로 구분. 오피스텔 안내 문구(HUG, 기준일 2026-10-14)
- v0.3 등기부 읽기 보완: 동·호수도 읽음(주소 대조에 필요)
- 계약서 값이 없으면 새 규칙은 등급을 막지 않음(기존 테스트 유지). 공시가격 입력칸과 부동산공시가격알리미 링크 추가

### v0.3 등기부 읽기 (2026-10-13)

- 등기사항전부증명서(집합건물) PDF 1개 또는 사진(JPG·PNG, 최대 10장, 합계 4MB)을 올리면 Claude(`claude-sonnet-5-5`)가
  소유자·지번 주소·전용면적·근저당(채권최고액·채권자, 변경 포함)·갑구 위험 기재(가등기 포함 6종)·소유권 이전일(접수일, 등기원인일 함께)을 읽어 옴
- AI는 서류 글자만 그대로 옮기고, 원→만원(올림)·근저당 최종 금액 합계·시군구 코드·집 종류·날짜 해석·"확인 필요" 판단은 코드가 함(설계 원칙 1)
- 서류에 없는 값은 비워 두고, 말소된 기재는 계산에서 빼고 "말소되어 제외한 기재"로만 보여 줌
- 값마다 원문 문장과 위치(예: 을구 1-1)를 보여 주고, AI가 자신 없거나 꼭 봐야 하는 값은 노란 칸 + "⚠ 확인 필요" 글자로 표시. 하나씩 확인해야 채우기 버튼이 눌림
- 전세권·임차권등기는 계산에 넣지 않고 항상 "⚠ 확인 필요"로 표시, 임차권등기에는 고정 설명(조문 원문 미확인 표시)
- 확인한 값은 위험 판정 칸(근저당 합계·갑구·이전일)과 시세 조회 칸(집 종류·주소·면적)에 채우고 "등기부에서 읽음" 표시. 손으로 고치면 표시가 사라짐. 시세 조회는 버튼으로
- 지원하지 않는 서류(집합건물 아님, 등기부 아님)와 읽을 수 없는 사진은 값 없이 안내만 함("다시 찍어 주세요")
- 올린 서류는 메모리에서만 다루고 저장·로그하지 않음. Anthropic 30일 보관 정책을 화면에 안내. API 키는 서버에서만 사용(빌드 결과물에 없음 확인)
- v0.1 위험 판정 코드(`src/rules`)는 그대로

### v0.2 시세 조회 (2026-10-13)

- 집 종류(아파트/빌라/오피스텔)·시도·시군구·법정동·지번·전용면적(㎡)으로 국토교통부 실거래가를 조회
- 시세 방법(승인): 같은 법정동·지번, 전용면적 ±10%, 최근 6개월 계약 중개거래 가격의 중앙값. 3건 미만이면 시세를 내지 않고 직접 입력 안내
- 취소 거래(cdealType "O")는 빼고 건수만 표시, 직거래는 목록에 "직거래 · 계산 제외"로 표시
- 추정 시세를 매매시세 칸에 자동으로 넣고 "실거래 추정값"으로 표시, 직접 수정 가능. v0.1 규칙 엔진은 그대로
- 인증키는 서버 경로에서만 사용(빌드 결과물에 없음 확인)
- 시군구 코드표: 공공데이터포털 "국토교통부_전국 법정동"(2026-07-29) 기준 256개
- 시세 기준값을 `config.ts`(MARKET_PRICE_METHOD)로 옮김(설계 원칙 5)
- 소유권 이전일을 등기부 표기 그대로 입력("2024년5월12일", "2024.5.12", "20240512" 등)하고 읽은 날짜를 표시
