# 전세레이더

등기부등본과 계약서를 올리면, 전세 사기·깡통전세 위험을 근거와 함께 알려주는 AI 에이전트 웹앱입니다.

> 이 도구는 법률 자문이 아니라 "확인을 돕는 도구"입니다.

## 실행 방법

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 규칙 엔진 테스트 (Vitest)
```

Node 24, npm 11에서 확인했습니다.

## 구조

- `src/rules/config.ts`: 위험 기준값과 출처·기준일
- `src/rules/engine.ts`: 위험 규칙 계산 (순수 함수)
- `src/app/`: 직접 입력 폼과 결과 화면
- `tests/engine.test.ts`: 규칙 엔진 테스트

## 버전 기록

### v0.1 규칙 엔진 (2026-10-08)

- create-next-app 16.4로 Next.js(App Router, TypeScript) 초기 설정, Vitest 설치
- `.gitignore`: 빌드 산출물과 `tests/fixtures`의 실제 서류를 막고 `fake-*`, `*.fake.*` 가상 문서만 허용
- 규칙 엔진: 전세가율(70% 이상 주의, 80% 이상 위험), 선순위 부담률(90% 초과 위험),
  갑구 위험 기재(가압류·압류·가처분·경매개시결정·신탁·가등기, 즉시 위험), 최근 소유권 이전(3개월 이내 주의)
- 값이 빠지거나 잘못되면 위험이 걸린 경우에만 등급을 내고, 그 외에는 등급 없이 빠진 값 목록을 보여줌
- 직접 입력 폼(금액 단위 만원)과 결과 화면: 등급(색+글자), 걸린 규칙과 기준·출처, 법률 자문 아님 안내
- 보증보험 기준(HUG)과 이름 비교 규칙은 v0.4용으로 `config.ts`에 값과 주석만 둠
