# 전세레이더

등기부등본과 계약서를 올리면, 전세 사기·깡통전세 위험을 근거와 함께 알려주는 AI 에이전트 웹앱입니다.

> 이 도구는 법률 자문이 아니라 "확인을 돕는 도구"입니다.

## 실행 방법

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 규칙 엔진·시세 추정 테스트 (Vitest)
```

실거래가 시세 찾기는 `.env.local`에 공공데이터포털 인증키가 필요합니다(커밋 금지).
국토교통부 아파트·연립다세대·오피스텔 매매 실거래가 API 세 개를 활용 신청해야 합니다.

```
DATA_GO_KR_KEY=발급받은_인증키
```

Node 24, npm 11에서 확인했습니다.

## 구조

- `src/rules/config.ts`: 위험 기준값과 출처·기준일
- `src/rules/engine.ts`: 위험 규칙 계산 (순수 함수)
- `src/data/marketPrice.ts`: 실거래가 조회와 시세 추정
- `src/data/regions.ts`: 시군구 코드표 (`scripts/build-regions.mjs`로 생성)
- `src/app/api/market-price/route.ts`: 서버에서만 인증키를 쓰는 시세 조회 경로
- `src/app/`: 입력 폼, 시세 찾기, 결과 화면
- `docs/api/`: 실거래가 API 기술문서와 필드 표(`fields.md`)
- `tests/engine.test.ts`, `tests/marketPrice.test.ts`: 테스트

## 버전 기록

### v0.2 시세 조회 (2026-10-13)

- 집 종류(아파트/빌라/오피스텔)·시도·시군구·법정동·지번·전용면적(㎡)으로 국토교통부 실거래가를 조회
- 시세 방법(승인): 같은 법정동·지번, 전용면적 ±10%, 최근 6개월 계약 중개거래 가격의 중앙값. 3건 미만이면 시세를 내지 않고 직접 입력 안내
- 취소 거래(cdealType "O")는 빼고 건수만 표시, 직거래는 목록에 "직거래 · 계산 제외"로 표시
- 추정 시세를 매매시세 칸에 자동으로 넣고 "실거래 추정값"으로 표시, 직접 수정 가능. v0.1 규칙 엔진은 그대로
- 인증키는 서버 경로에서만 사용(빌드 결과물에 없음 확인)
- 시군구 코드표: 공공데이터포털 "국토교통부_전국 법정동"(2026-07-29) 기준 256개

### v0.1 규칙 엔진 (2026-10-08)

- create-next-app 16.4로 Next.js(App Router, TypeScript) 초기 설정, Vitest 설치
- `.gitignore`: 빌드 산출물과 `tests/fixtures`의 실제 서류를 막고 `fake-*`, `*.fake.*` 가상 문서만 허용
- 규칙 엔진: 전세가율(70% 이상 주의, 80% 이상 위험), 선순위 부담률(90% 초과 위험),
  갑구 위험 기재(가압류·압류·가처분·경매개시결정·신탁·가등기, 즉시 위험), 최근 소유권 이전(3개월 이내 주의)
- 값이 빠지거나 잘못되면 위험이 걸린 경우에만 등급을 내고, 그 외에는 등급 없이 빠진 값 목록을 보여줌
- 직접 입력 폼(금액 단위 만원)과 결과 화면: 등급(색+글자), 걸린 규칙과 기준·출처, 법률 자문 아님 안내
- 보증보험 기준(HUG)과 이름 비교 규칙은 v0.4용으로 `config.ts`에 값과 주석만 둠
