## 참고
- 이용 조건: 정부·공공기관이 공개한 자료입니다. 보도자료는 공공누리 제1유형(출처표시)입니다. 화면에는 항상 문서명·기관·쪽(조문)을 출처로 표시합니다.
- "뺄 쪽"은 PDF 순서로 적습니다. 그림뿐이거나 빈 쪽, 서명란·설문처럼 검색에 쓸 내용이 없는 쪽을 뺍니다.
- `molit-guide.pdf`는 PDF 순서와 인쇄된 쪽 번호가 다릅니다(예: PDF 5번째 쪽 = 인쇄 3쪽). 출처에는 인쇄된 쪽 번호를 보여줍니다.
- 보도자료 주소는 국토교통부 보도자료 목록입니다. 목록에서 제목이나 배포일(2025.8.27)로 찾을 수 있습니다.
- `molit-press-333.pdf`의 4~6쪽(포스터·체크리스트)은 그림이라 글자를 뽑을 수 없습니다.
- `standard-lease-contract.pdf`의 5쪽은 별지(계약갱신 거절통지서)입니다.
- 법령과 HUG 기준은 위 날짜 기준입니다. 개정되면 문서와 `src/rules/config.ts`를 함께 갱신합니다.
